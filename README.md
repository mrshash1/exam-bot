# 🎓 ربات آزمون آنلاین تلگرام

ربات تلگرامی ساخت و برگزاری آزمون با **۳ حالت**: متنی، اپ (داخل تلگرام) و سایت — با **تایمر متحرک زنده**، **نمره منفی کنکوری (پیش‌فرض)** و اجرای ۲۴/۷ روی **GitHub Actions**.

- 🤖 ربات: [@mykonkuriexam2bot](https://t.me/mykonkuriexam2bot)
- 🌐 سایت آزمون: https://mrshash1.github.io/exam-bot/

---

## 🚀 نحوه اجرا (برای مالک ربات)

هیچ کاری لازم نیست! ربات روی سرور گیت‌هاب (GitHub Actions) اجرا می‌شود:

1. ربات هر ~۵ ساعت خودش را ری‌استارت می‌کند (خودکار).
2. اگر کرش کند، بلافاصله خودش دوباره بالا می‌آید.
3. همه داده‌ها (آزمون‌ها، نتایج) داخل همین مخزن ذخیره می‌شوند:
   - `exams/<code>.json` → تعریف عمومی آزمون (بدون کلید پاسخ!)
   - `data/vault/<code>.json` → کلید پاسخ‌ها و نتایج (**رمزنگاری‌شده** با توکن ربات)
   - `data/sessions.json` و `data/wizards.json` → جلسات در جریان و پیش‌نویس‌ها (رمزنگاری‌شده)

### 🔑 تغییر توکن ربات یا توکن گیت‌هاب (در آینده)
به `Settings → Secrets and variables → Actions` در همین مخزن بروید و مقدار این دو Secret را به‌روز کنید:
- `BOT_TOKEN` → توکن ربات تلگرام (از @BotFather)
- `GH_PAT` → توکن شخصی گیت‌هاب با دسترسی `repo` + `workflow`

بعد از تغییر، از تب Actions یک بار «exam-bot → Run workflow» را بزنید.

## 👩‍🏫 راهنمای استفاده از ربات

### ساخت آزمون (دبیر)
1. در ربات دکمه **«📝 ساخت آزمون جدید»** را بزن.
2. **نام آزمون** را بفرست → بلافاصله **کارت اطلاعات آزمون** نمایش داده می‌شود (کد، لینک‌ها، تنظیمات).
3. **سوالات** را بفرست — پیام متنی یا فایل `.txt`. قالب:
```
1. متن سوال؟
الف) گزینه ۱
ب) گزینه ۲
ج) گزینه ۳
د) گزینه ۴
پاسخ: ب

2. سوال بعدی؟
...
پاسخ‌ها: 1-الف، 2: 60   ← یا کلید را یکجا در آخر بفرست
```
   - سوال تشریحی/کوتاه‌پاسخ: بدون گزینه، با خط `پاسخ: متن`
   - فایل JSON هم قابل قبول است: `[{"q":"سوال؟","o":["الف","ب"],"a":0}]`
4. دکمه **«✅ انتشار آزمون»** را بزن → لینک‌ها فعال می‌شوند:
   - 🔗 لینک مستقیم ربات: `https://t.me/mykonkuriexam2bot?start=exam_کد`
   - 🌐 لینک سایت با تایمر زنده: `https://mrshash1.github.io/exam-bot/exam.html?e=کد`
   - 🆔 کد ۶ رقمی آزمون

### حالت‌های برگزاری
| حالت | توضیح |
|------|-------|
| ✍️ متنی | سوال‌ها داخل چت با دکمه؛ نمایش زمان باقی‌مانده + هشدار ۵ و ۱ دقیقه + پایان خودکار |
| 📱 اپ | دکمه «حالت اپ» صفحه آزمون را داخل خود تلگرام باز می‌کند — تایمر متحرک زنده + ارسال خودکار نتیجه |
| 🌐 سایت | لینک در هر مرورگری باز می‌شود — تایمر متحرک زنده + کد نتیجه برای ارسال به ربات |

### تنظیمات هر آزمون (دکمه ⚙️)
- ⏱ مدت (دقیقه)
- ➖ **نمره منفی: پیش‌فرض ۱/۳ کنکوری** (بدون / ۱/۳ / ۱/۴ / ۱/۲ / عدد سفارشی)
- 🎟 تعداد مجاز شرکت هر نفر (۱ پیش‌فرض / ۲ / ۳ / نامحدود)
- 🔒 دسترسی: فقط با لینک/کد (پیش‌فرض) یا عمومی (نمایش در سایت)
- 🖋 روشن/خاموش کردن هر یک از ۳ حالت
- ▶️ شروع زمان‌بندی از الان / ⛔ پایان آزمون / 🧹 حذف بازه
- ➕ افزودن یا 🔄 جایگزینی سوالات
- 📊 نتایج (جدول رتبه‌بندی) و 📄 خروجی CSV

### شرکت در آزمون (دانش‌آموز)
- روی لینک دبیر کلیک کن، یا کد ۶ رقمی را در ربات بفرست.
- در حالت سایت/اپ: نام را وارد کن، آزمون را بده؛ در پایان نتیجه خودکار (اپ) یا با کد نتیجه (سایت) به ربات می‌رسد و کارت نمره + رتبه را می‌بینی.

## 🛠 ساختار پروژه
```
bot/
  main.py      # حلقه اصلی، روتر پیام‌ها، polling
  tg.py        # کلاینت Telegram Bot API
  gh.py        # کلاینت GitHub Contents API (ذخیره‌سازی)
  store.py     # مدیریت state (آزمون‌ها/نتایج/جلسات) + رمزنگاری
  crypto.py    # رمزنگاری متقارن مبتنی بر توکن (SHA-256 stream + HMAC)
  parser.py    # پارسر سوالات (فارسی/انگلیسی، فایل txt/json)
  scoring.py   # تصحیح + نمره منفی + کد نتیجه وب
  wizard.py    # ویزارد ساخت/تنظیمات آزمون
  run.py       # اجرای آزمون متنی (تایمر زنده) + ثبت نتایج وب/اپ
  views.py     # کارت‌ها، منوها، جدول نتایج، CSV
web/
  exam.html/js/css  # اپ آزمون (Mini App تلگرام + سایت) با تایمر زنده
  index.html        # صفحه اصلی سایت + لیست آزمون‌های عمومی
.github/workflows/bot.yml  # اجرای ۲۴/۷ روی GitHub Actions
```

## 🔐 امنیت
- کلید پاسخ‌ها **هرگز** در فایل عمومی یا مرورگر نمایش داده نمی‌شود؛ تصحیح روی سرور ربات انجام می‌شود.
- فایل‌های خصوصی با کلید مشتق‌شده از **توکن ربات** (که فقط در Secrets گیت‌هاب است) رمزنگاری می‌شوند.
- ثبت نتیجه محدود به: تعداد مجاز شرکت، بازه زمانی آزمون، و شناسه تلگرامی هر نفر.
